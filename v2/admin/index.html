Nova estrutura

Como o fluxo foi organizado

1. Cliente gerente

O cliente principal pode entrar no painel e criar usuarios para cada professor.

2. Limite por dispositivos

A quantidade de usuarios de professor fica limitada ao numero de dispositivos contratado.

3. Telemetria do app

O painel recebe total de alunos, turmas e quantidade de logins por usuario.

4. Dispositivo unico

Cada usuario pode ser vinculado a um unico aparelho, preservando o banco local de cada professor.

Operacao

Pronto para web, desktop e outros aparelhos

1. Painel web

Hospede o Controle AlfaTec no Vercel para o admin acessar de qualquer computador pelo navegador.

2. Servidor publico

As rotas da assinatura continuam apontando para o backend publico configurado no deploy.

3. Professores

Crie um usuario por professor e acompanhe senha, logins, alunos e dispositivo vinculado.

O painel agora foi preparado para administracao central via navegador e uso distribuido em varias maquinas.
